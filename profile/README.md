### 🧠 The Mission: Determinism Over Hallucination

When AI coding agents (like **Claude Code**, **Cursor**, or **VS Code Copilot**) perform complex refactors or multi-repository tasks, they rely on basic file grepping and raw text trees. They guess relationships and miss breaking changes down the call chain.

**Enola Labs** builds high-performance, local structural parsers. We extract typed dependency graphs straight from multi-language source code and serve them via the **Model Context Protocol (MCP)**—giving AI agents and developers the architectural context as tey need it.
